# Enable HiSparse for DSA models on ROCm

## Summary

This change enables HiSparse for DeepSeek-style DSA models on ROCm, validated on MI355X, while keeping CUDA behavior unchanged. ROCm uses TileLang as the default HiSparse DSA backend, supports FP8 and BF16 KV cache, and can also run with AITE
