## Summary

The three extend lens cpu fields are declared `Optional[List[int]]`, and the `*_cpu` family convention is: tensor mirrors (`seq_lens_cpu`) stay tensors, host bookkeeping lists (`encoder_lens_cpu`, `global_num_tokens_cpu`, `extend_*_cpu`) stay lists. Two producers violated this and stored CPU tensors

## Problem

[Fix] Unify ForwardBatch extend lens cpu fields to their declared list type
