## Summary

This PR adds a Python-only `FLASH_ATTN_MLA_SPARSE` backend for sparse MLA
models on Hopper GPUs. The backend reuses vLLM's existing FlashAttention MLA
wrapper and sparse MLA index conversion path, then calls
`flash_attn_varlen_func(..., fa_version=3)` for BF16 KV-cache sparse decode
