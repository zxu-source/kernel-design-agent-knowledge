## Summary

`RMSNorm(has_weight=False)` (FlashNorm-folded checkpoints, #40117) only skipped the per-channel multiply on the native path. The CUDA/CPU `_C` kernels required a weight tensor, so the layer substituted an all-ones tensor and ran the weighted kernel — correct, but a wasted load + multiply. Fixes #414
