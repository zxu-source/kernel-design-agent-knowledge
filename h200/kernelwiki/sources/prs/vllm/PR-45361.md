## Summary

### What this PR does

This PR fixes the Triton reshape-and-cache path for `kv_cache_dtype=int8_per_token_head`.

The per-token-head KV cache kernel computes one absmax scale per `(token, head)`, but the INT8 path previously clamped the scaled K/V values and then relied on the implicit float-to-int8
