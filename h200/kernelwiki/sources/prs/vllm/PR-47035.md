## Summary

## Purpose
Encoder-decoder models (Whisper, Nemotron-Parse, ...) share one raw KV allocation between decoder self-attention (`ROCM_ATTN`, K/V-first) and cross-attention (`AITER`/`TRITON`, blocks-first). The mismatched stride conventions over the same bytes cause aliasing → garbage / repeated-token 

## Problem

[ROCm] Fix encoder-decoder cross-attention KV layout aliasing
