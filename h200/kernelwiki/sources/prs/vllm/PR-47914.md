## Summary

Enables DFlash drafters that mix sliding-window and full-attention layers (e.g. z-lab/Qwen3.5-35B-A3B-DFlash) on the V2 model runner, by giving each KV cache group its own causal attention metadata so the sliding-window layers run causal and the full-attention layers non-causal.

Also fixes lm_head
