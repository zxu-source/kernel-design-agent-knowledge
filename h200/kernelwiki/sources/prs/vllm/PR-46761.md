## Summary

# Context
Currently in `DFlashQwen3Model` during `precompute_and_store_context_kv` we invoke `rms_norm` for each layer in a loop, resulting in multiple kernel launches. This is done because rms_norm only supports broadcasting the single `[hidden_size]` weights to all rows of the input.

## Problem
