## Summary

`group_and_unify_kv_cache_specs()` targets DeepseekV4, where MLA and sliding-window MLA layers have different page sizes and must be tuple-packed. 
It fired for any model containing a SlidingWindowMLASpec, so a non-DeepseekV4 model with a uniform page size was wrongly pushed into the packing path. 

## Problem

[Bugfix][KV Cache] Don't route uniform-page-size MLA+SWA models into DeepseekV4 packing
