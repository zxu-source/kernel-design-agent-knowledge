## Summary

## Purpose

Mistral Small 4 uses MLA head dimensions (qk_nope_head_dim=64, qk_rope_head_dim=64, v_head_dim=128). `FlashAttnPrefillBackend.supports_mla_dimensions` did not list these dims, so the model was excluded from the FlashAttention MLA prefill backend. This adds the config to the supported set

## Problem

[Bugfix] Enable FlashAttention MLA prefill for Mistral Small 4 head dims
