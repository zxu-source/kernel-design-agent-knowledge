## Summary

This PR adds an opt-in ROCm AITER implementation for MiniMax-M3 sparse attention.

MiniMax-M3 sparse attention selects top-k logical blocks of 128 tokens. This PR maps those selected 128-token blocks into AITER page-16 block tables and runs AITER Gluon paged attention over only the selected KV pag
