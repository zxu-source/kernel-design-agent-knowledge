## Summary

vLLM does not pass `tune_max_num_tokens` to FlashInfer’s BF16, FP8, and NVFP4 TRT-LLM MoE kernels. FlashInfer therefore ends autotuning at its default maximum bucket of 8192.

This can be too low. The estimated maximum token count is: `DP size * max_num_batched_tokens`

Larger inputs still run, 

## Problem

[MoE] FI autotuning: max bucket = max token count [e.g. `DP_size*MNBT`]
