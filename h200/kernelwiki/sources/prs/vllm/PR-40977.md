## Summary

Add a hybrid W4A16 linear kernel for ROCm gfx11/gfx12 that routes between two GEMM implementations based on batch size:
- M <= 5: HIP wvSplitK_int4_g skinny GEMM (optimized for single-token decode)
- M > 5: Triton fused dequant GEMM (optimized for prefill/batched inference)

Both paths share a s
