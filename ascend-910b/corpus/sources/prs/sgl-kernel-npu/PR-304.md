## Upstream description

### Modification:
Added an environment variable to control whether to enable the Combine Ant Migration feature.

### Using:
`export DEEPEP_NORMAL_COMBINE_ENABLE_LONG_SEQ=1` to enable the Combine Ant Migration feature. Disable By default. And first, you need to activate the dispatch ant moving service by setting `DEEPEP_NORMAL_LONG_SEQ_ROUND`  and `DEEPEP_NORMAL_LONG_SEQ_PER_ROUND_TOKENS`.
