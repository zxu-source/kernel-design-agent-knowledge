## Upstream description

Optimize the function assign_req_to_token_pool in SGLang MTP scenarios to reduce execution time from around **8.x ms** (torch native implementation) to around **0.4 ms** (AscendC implementation).

This operator supports most data types, including torch.int8, torch.int16, torch.int32, and torch.int64. It should also support floating point types, but these have not yet been validated. **The index inputs must be restricted to torch.int64/torch.long (8 bytes)**.
