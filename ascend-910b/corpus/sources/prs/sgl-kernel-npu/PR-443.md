## Upstream description

- **New optional `attentions` module** – added to the build system with the `BUILD_ATTENTIONS_MODULE` flag so you can choose whether to compile and include these kernels.  
  Enabled by default. When building, the flag **determines whether the module is built or not**.
  - `laser_attention` – LASER attention kernel
  - `block_sparse_attention` – block‑sparse attention 
  - `sparse_block_estimate` – for block‑sparse attention 
  - `rainfusionattention` – RainFusion attention kernel
  - `layernorm` – optimized layer normalization kernel
- **Build system updates**
  - Separate compilation step via `build_attentions_kernels` (sources in `csrc/attentions/build`)
  - Packaging step via `make_attentions_package` produces a standalone `attentions*.whl` in `OUTPUT_DIR`

### How to build
```bash
# Build the library with attention kernels enabled (default)
bash build.sh
```
After a successful build, you will find the wheel inside the output directory.

The kernels are registered as standard PyTorch custom ops under torch.ops.attentions
### How to use 
```python
import attentions
import torch 
# next use torch.ops.attentions
```

The tables with measurements can be found in this PR: https://github.com/sgl-project/sglang/pull/23482
