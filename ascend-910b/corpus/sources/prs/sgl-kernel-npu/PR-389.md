## Upstream description

This PR adds support for batched execution of causal_conv1d_fn to get rid of the loop.

The code was tested on benchmarks for the Qwen3-Next-80B-A3B-Instruct gsm8k, bench_serving model with different input parameters.

#### Environment
- python 11
- up-to-date sglang, sgl_kernel_npu
- torch, torch_npu 2.8.0
- CANN 8.5.0

#### Run model command:
python -m sglang.launch_server --device npu --attention-backend ascend --trust-remote-code --tp-size 8 --mem-fraction-static 0.5 --cuda-graph-bs 1 2 4 16 64 128 256 512 1024 2048 4096 8192 --disable-radix-cache –chunked-prefill-size=8192

#### gsm8k benchmark command:
python ./bench_sglang.py --num-questions 1319 --data-path ./test.jsonl --parallel 256

#### bench_serving command
python -m sglang.bench_serving --backend sglang --random-range-ratio 1.0 --num-prompts 1319 --max-concurrency 256 --random-input-len 1024 --random-output-len 1024 --flush-cache

(small queries)
python -m sglang.bench_serving --backend sglang --random-range-ratio 1.0 --num-prompts 1319 --max-concurrency 256 --random-input-len 50 --random-output-len 50 --flush-cache
