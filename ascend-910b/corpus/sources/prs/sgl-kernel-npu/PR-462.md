## Upstream description

Changes:

- Integrate pto-isa mega-kernel for `chunk_gated_delta_rule_fwd` used by models such as Qwen 3.5/3.6.
  - The mega-kernel combines the 6 kernels (cumsum, chunk_h, chunk_o, dot_kkt, tri_inverse, wy_fast) into a single kernel launch. See [megagdn-pto blog post](https://github.com/huawei-csl/megagdn-pto/blob/main/blog/mega_gdn_en.md) for more info. 
 
- Add pto-isa as a submodule


The new mega-kernel is dispatched instead of the triton kernel when number of heads are supported (see exact conditions in `mega_chunk_gdn`). To force the triton kernel to run, set `GDN_ATTN_BACKEND_TRITON=1`.
We support
- `initial_state` (812941ed473515f38e44c5c485d010cf853512e6)
- `output_final_state` (f0c530843fed4bfc04fd4b76a3328b3eede9f3ca)


## Tests

- Kernels are verified numerically on Atlas A2, and should be compatible with A3 aswell (as the isa is identical).
- Tested on both CANN 8.5.0 with triton 3.2.0 and 9.0.0 with triton 3.2.1
- A5/950 is not yet supported, since there are small differences in the cube-vector communication interface.

Mega-kernel passes test with torch reference (`chunk_gated_delta_rule_native`):

```bash
pytest -s tests/python/sgl_kernel_npu/test_mega_chunk_gdn.py
```

## Perf


Using sglang version: 0.5.12.dev371+g9e00b7ca9 and 910B2

```bash
python -m sglang.bench_one_batch --model-path Qwen/Qwen3.5-X --batch-size 1 1 1 1 1 1 1 --input-len 32 64 128 256 512 1024 2048 4096 8192 16384 32768 --output-len 32 --run-name mega/triton-qwen35_X --context-length 35000 --max-total-tokens 35000 --disable-radix-cache
```
We see between 2-8 % speed up across all input lengths tried in (32, 32k) for Qwen 3.5 0.8B/9B. Run each prefill 7 times and use the median time (numbers are similar for mean&max). I'm seeing an even better speed improvement in the more realistic `sglang.bench_serving` benchmark, reaching 15% in cases.

### Supported shapes 
Currently we support Qwen 3.5/3.6 with `TP=1`, and a few more (bold values are supported)

Format: (num val heads, num key heads)
  | Global $H_v$ | TP=1 | TP=2 | TP=4 | TP=8 |
  |---:|---|---|---|---|
  | 16 | **(16,16)** | (8,8) | (4,4) | (2,2) |
  | 32 | **(32,16)** | **(16,8)** | (8,4) | (4,2) |
  | 48 | **(48,16)** | (24,8) | (12,4) | (6,2) |
  | 64 | **(64,16)** | **(32,8)** | **(16,4)** | (8,2) |
