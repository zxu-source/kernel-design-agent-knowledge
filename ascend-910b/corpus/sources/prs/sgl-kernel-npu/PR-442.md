## Upstream description

This PR introduces the apply_token_bitmask operator.
When speculative decoding is enabled in SGLang and a user request requires a JSON Schema output format, the xgrammar_backend will be triggered. It contains the operator apply_token_bitmask_inplace_triton, which cannot run on NPU. The alternative CPU fallback solution suffers from poor performance, so an AscendC-based apply_token_bitmask operator is implemented.
Integration into SGLang has been completed, along with single-concurrency validation and performance benchmarking.
In single-concurrency scenarios, the average latency of the CPU fallback implementation is 4.48 ms, while the AscendC bitmask operator reduces the average latency to 0.171 ms.
