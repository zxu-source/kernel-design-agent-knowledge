## Upstream description

**Problem:**
Model: Qwen3.5-35B, TP=2
Enabled Features:
export DEEPEP_NORMAL_LONG_SEQ_ROUND=32
export DEEPEP_NORMAL_LONG_SEQ_PER_ROUND_TOKENS=3584

**Phenomenon:**
The error "The MPU address access is invalid" occurs in the notify_dispatch kernel.

**Cause Analysis:**
With 128 experts per NPU and the round parameter set to 32, the operator's Unified Buffer (UB) usage exceeds hardware limits.

**Solution:**
Reduce the batchRounds value when the number of experts per NPU is large.
