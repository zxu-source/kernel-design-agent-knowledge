## Upstream description

## Motivation

If the SGLANG_DEEPEP_NUM_MAX_DISPATCH_TOKENS_PER_RANK environment variable is configured on the framework side, it will be passed as the input parameter `num_max_dispatch_tokens_per_rank` of the decode operator to the operator for each rank to determine the size of the tensor and HCCL buffer to be allocated. However, the current logic cannot determine whether the SGLANG_DEEPEP_NUM_MAX_DISPATCH_TOKENS_PER_RANK configured for each rank is large enough when the batch size is dynamic. Therefore, an assert check is added at the operator entry to ensure that the max_token configured for each rank is large enough.

## Modification

Added the verification of num_max_dispatch_tokens_per_rank to the decode operator adaptation layer.
