## Upstream description

normal_dispatch num_recv_tokens_per_expert_list support prefixSum
Controlled by the environment variable `MOE_EXPERT_TOKEN_NUMS_TYPE`: 0 indicates the prefix sum of the number of tokens received by each expert, and 1 indicates the number of tokens received by each expert (default).  

To return the prefix sum, set: 
```bash
export MOE_EXPERT_TOKEN_NUMS_TYPE=0
```
